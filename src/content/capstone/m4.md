## Evaluation of the Ubiquiti Cloud Gateway Ultra Guide

<p style="margin-bottom: 1.5rem; line-height: 1.75;">
  While Ubiquiti hardware is industry-leading, their installation guide is overly minimalist. It relies almost entirely on pictures with zero written troubleshooting help, which can intimidate users without strong technical skills.
</p>

<p style="margin-bottom: 1.5rem; line-height: 1.75;">
  The document lacks information that might help a layperson understand what they are doing. For example, the "Package Contents" uses labels "a" through "d" without a key, leaving users to guess about the specific hardware they are holding.
</p>

<hr style="border: 0; border-top: 1px solid rgba(255,255,255,0.1); margin: 2rem 0;" />

## Technical Safety Nets

<p style="margin-bottom: 1.5rem; line-height: 1.75;">
  I propose adding a "Pre-Configuration" checklist and a "Troubleshooting" box to turn the guide into a real, functional tool:
</p>

<ul style="margin-bottom: 2rem; padding-left: 1.25rem; list-style-type: disc;">
  <li style="margin-bottom: 0.75rem; line-height: 1.75;">
    <strong style="color: #98BF92;">Power-On Verification:</strong> Wait for the "Ready for Setup" prompt on the device screen.
  </li>
  <li style="margin-bottom: 0.75rem; line-height: 1.75;">
    <strong style="color: #98BF92;">Bluetooth Connectivity:</strong> Ensure the mobile device has Bluetooth enabled and is within 5 feet of the gateway.
  </li>
  <li style="margin-bottom: 0.75rem; line-height: 1.75;">
    <strong style="color: #98BF92;">Status Light:</strong> Do not open the UniFi app until the gateway displays a steady light pattern.
  </li>
</ul>

<div style="border-left: 4px solid #98BF92; padding: 1.25rem 1.5rem; margin-bottom: 2rem; background: rgba(255,255,255,0.02); border-radius: 0 6px 6px 0;">
  <h3 style="margin-top: 0; margin-bottom: 1rem; font-size: 1.15rem; font-weight: bold; color: #ffffff;">🛠️ Troubleshooting Protocols</h3>
  <ul style="margin: 0; padding-left: 1.25rem; list-style-type: square;">
    <li style="margin-bottom: 0.5rem; line-height: 1.6; color: rgba(255,255,255,0.85);">
      <strong>If the device does not power on:</strong> Verify the USB-C cable is fully seated in both the gateway and the outlet.
    </li>
    <li style="line-height: 1.6; color: rgba(255,255,255,0.85);">

    </li>
